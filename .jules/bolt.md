## 2025-05-20 - Concurrent Claim Check Payload Processing with asyncio.gather
**Learning:** Temporal PayloadCodec `encode` and `decode` methods accept an iterable of `Payload` objects for batch processing. Processing payloads sequentially in an `async` loop introduces linear latency scaling for network I/O ($O(N \times \text{S3 latency})$). Since `asyncio.gather` guarantees returning results in the exact same order as input tasks, wrapping individual payload codec operations into coroutines executed concurrently with `asyncio.gather` reduces total batch processing latency to $O(\text{S3 latency})$ while safely preserving payload sequence integrity.
**Action:** When implementing or optimizing custom Temporal `PayloadCodec` implementations with async I/O (such as S3, key management systems, or external storage), always process batch payload arrays concurrently with `asyncio.gather` instead of sequential `for` loop awaits.
